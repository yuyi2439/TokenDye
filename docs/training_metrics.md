# TokenDye 训练日志指标说明

每次训练会生成一个以**启动时间**命名的子目录（默认在
`example/Qwen3.5/.outputs/<启动时间>/` 下），里面包含：

- `train.log`：训练日志（实时输出，也会同步打印到终端）
- `dye_final.pt` / `dye_dapo_final.pt`：训练好的染色权重

日志每 `--log-every` 步打印一行指标，下面逐个解释。

## 指标逐条说明

### loss（总损失）

训练要优化的总目标。SFT 阶段：

```text
loss = ce_resp + w_anchor × anchor
```

（`weight_decay` 通过优化器直接作用在参数上，不显示在 loss 里。）
数值越低代表整体越好。

### ce_resp（response 段的交叉熵）

只计算**最终正文（response 段）** token 上的交叉熵损失。

简单理解：模型每生成一个 token，都要预测“下一个最可能是哪个词”。
交叉熵衡量“预测概率”和“真实下一个词”之间的差距——真实词预测概率越高，
损失越小。ce_resp 就是只在正文段上算这个差距，是 SFT 的**主目标**：

- 训练开始时正文基本接不上，ce_resp 较大（例如 2.5+）；
- 训练后下降（例如 0.4~0.5），说明染色后的模型已经能照训练正文好好接话。

### anchor（保真约束）

衡量染色对**不该动的内容**的干扰。

训练时用冻结的基座模型跑一遍，把 **prompt 段（system/user/工具/历史轮次）**
最后一层的隐藏状态和“染色后的模型”做对比，取均方误差（MSE）：

```text
anchor = mean((h_dyed - h_base)^2)   只统计 prompt 段
```

- 越小越好：0 表示染色完全没碰 prompt 段；
- 注意：δ=0 时 dyed 和 base 完全相同，anchor=0 **且梯度也是 0**，
  所以训练早期必须靠 ce_resp 先把 δ 推离 0，anchor 才会开始起作用。

### |delta|（染色强度）

染色参数 `delta` 的绝对值均值。有效缩放是 `1 + delta`：

- `|delta| ≈ 0`：还没染色（等价原模型）；
- `|delta| ≈ 0.05~0.1`：温和的染色，缩放大约在 0.95~1.05 之间；
- 持续快速增大：说明染色在变强，需要关注是否跑飞（脚本里有 clamp 保护）。

### grad（梯度范数）

染色参数梯度的范数（经过 clip 之后）。用来判断优化是否正常：

- 正常训练中在 0.3~1.0 之间波动；
- 长期为 0：说明没有学习信号（通常是数据/掩码问题，应报错而不是静默）。

### vram（显存占用）

本次运行到目前为止分配过的**峰值显存**（GB）。12GB 的卡建议留 1~2GB 余量。

### decay_diff（退化指标，重点盯）

衡量染色把 **prompt 段模型输出分布改了多少**。计算方式：

```text
对每个 prompt token：
    diff = max over 词表( |dyed_logits - base_logits| )   # 该位置最大变化
decay_diff = mean over prompt tokens( diff )
```

- 0：完美零损伤（染不染完全一样）；
- 1 以内：可以接受；
- 持续涨到 3~5+：染色明显干扰了 prompt 段，应该**加大 `--w-anchor`**
  （例如 0.1 → 0.3~0.5），或考虑把 anchor 换成 prompt 段的 logit 级 KL。

它和 anchor 是同一个问题的两个视角：anchor 看隐藏状态，decay_diff 看最终输出分布。

### 角色 δ 余弦相似度矩阵

每次打印一个 4×4 矩阵，行列对应 `system / user / agent / response`：

```text
1.000 0.123 0.000 0.016
0.123 1.000 0.000 0.047
0.000 0.000 0.000 0.000
0.016 0.047 0.000 1.000
```

含义：把每个角色的 δ 跨层平均、做 L2 归一化，再两两算余弦相似度。

- 越接近 1：两个角色的染色方式越像；
- 越接近 0：越正交（角色分化越明显）；
- **agent 行/列全 0 是正常的**：训练数据里没有 agent（think）段，
  `delta[agent]` 保持初始值 0，零向量和谁相似度都是 0。它是预留标签。

## 怎么快速判断训练是否正常

| 现象 | 结论 |
|---|---|
| ce_resp 持续下降 | ✅ 在学，正常 |
| \|delta\| 缓慢增长 | ✅ 染色在生效 |
| decay_diff 持续升高 | ⚠️ 调大 `--w-anchor` |
| loss 抖动很大 | 正常现象，batch 小/样本差异大 |
| grad 长期为 0 | ❌ 没有学习信号，查数据 |
| agent 行列全 0 | ✅ 正常（休眠标签） |
